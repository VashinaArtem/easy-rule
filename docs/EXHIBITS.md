# Открытые работы

## Зал I. Бесконечность

### Множество Мандельброта (`/work/mandelbrot`)
`z → z² + c`, старт с нуля. Плавная окраска по итерации, оценка расстояния для тонкой границы. При `scale ≲ 4·10⁻⁴` включается df64; пол `~4·10⁻¹¹`. Есть готовые места (морские коньки, долина слонов, глубина ×10⁹) и врезка Жюлиа для точки прицела.

### Множества Жюлиа (`/work/julia`)
То же правило при фиксированном `c`. Карта Мандельброта выбирает `c`; обход по границе кардиоиды; пресеты (кролик Дуади, диск Зигеля, Сан-Марко…). Связность: `c ∈ M` ↔ множество связно.

### Бассейны Ньютона (`/work/newton`)
`z → z − a·p(z)/p'(z)`, где `p'/p = Σ 1/(z−rᵢ)`. Корни — перетаскиваемые кольца (до 6); `a` меняет длину шага. Цвет — к какому корню сошлась точка.

## Зал II. Хаос и рождение формы

### Аттрактор Лоренца (`/work/lorenz`)
Классические σ=10, ρ=28, β=8/3; RK4. Облако точек или две близкие траектории («бабочки»). Показатель Ляпунова ≈ 0,906; бифуркация Хопфа при ρ ≈ 24,74. Точки покоя можно показать явно.

### Реакция и диффузия (`/work/gray-scott`)
Модель Грея–Скотта, Du=1, Dv=0,5, dt=1, 9-точечный шаблон. Предустановки (лабиринт, пятна, червяки…), кисть, атлас F–k. Кривая седло-узла `k = √F/2 − F`. Нужен `EXT_color_buffer_float`.

## Зал III. Гармония

### Эпициклы Фурье (`/work/fourier`)
Контур (сердце, звезда, квадрат…) пересэмплируется по длине дуги (M=512), DFT, эпициклы по убыванию |cₙ|. Режим рисования своей линии.

### Таблица умножения на круге (`/work/modular`)
Хорды `i → k·i (mod n)`. Огибающая: кардиоида при k=2, нефроида при k=3; формула `A cos mθ + B sin mθ` с `m=(k+1)/2`, `d=(k−1)/2`.

## Зал IV. Измерения

### Расслоение Хопфа (`/work/hopf`)
`h(z₁,z₂) = (2z₁z̄₂, |z₁|²−|z₂|²)`, стереографическая проекция из (0,0,0,1). Параллель → тор вложенных окружностей; «вся сфера» — фибоначчиева выборка; свои точки на базе. Число зацепления двух первых волокон (интеграл Гаусса). Поворот в плоскости x₁–x₄.

## В подготовке

Раскраска комплексных функций, аполлониева сетка, клеточные автоматы, аттракторы Клиффорда/де Йонга, Лиссажу, мозаики Пенроуза, гиперболическая плоскость, гироид, поверхность Боя, симметрия E₈.
